Elgato Stream Deck REST API & Macro Guide

Zero-authentication endpoints for physical macro pads, Loupedeck, or browser shortcuts.

💡 How to Configure Elgato Stream Deck in 30 Seconds:
  1. In the Elgato Stream Deck app, drag a "System > Website" action onto any key.
  2. Paste any URL below into the URL field (e.g. http://127.0.0.1:8000/api/streamdeck/combat/next-turn).
  3. Check the box "GET request in background" so no browser tab opens!
  4. (Optional) For two-way status and feedback, plugins like "API Ninja" or "HTTP Request" are also fully supported with GET or POST.
All endpoints accept both GET and POST without session cookies.
